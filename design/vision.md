# VISION

以后要到达哪里。**这一份不是设计，也不装进度**：规矩在 `BEHAVIOR.md`，拍过板的决定在
`memo.md`，还没做的在 `重构待办.md`，正在干什么在 `PROGRESS.md`。

每一条写两样：**最后长什么样**，以及**现在为它留了什么口**（留了口的说明当时是照着它设计的；
没留口的就直说没留）。一条实现了就从这份里去掉，设计细节搬进对应域的
`README.md` / `ARCHITECTURE.md`。

---

## 1. 两个前端同看一条会话

**长成什么样**：两个界面开同一条会话，一个发动，另一个跟着同步；两个都把话打进去也不打架 ——
第二个收到的就是「忙」。

**留了什么口**：一条会话一人一条流；`submit` / `compact` 只回「开了 / 忙」，内容一概从流上来；
`StreamItem::Ended` 带回合号，两个前端各自知道是哪一段收尾了。

---

## 2. 对外的传输只留一套

**长成什么样**：**形状只有一套，边缘将来有两套。** 一套形状（`Call` / `Post` / `Subscribe` /
`StreamItem`）谁都走；本机那两个进程之间走 unix socket（Windows 上是命名管道），**不占端口**；
以后网页与手机走另一扇门 —— 一个真的 HTTP 边缘（TCP、有端口、按需开），把同一套形状翻译过去。

**留了什么口**：形状本来就是枚举进、枚举出、一人一条流，直接能序列化（`ipc` 那一层加的就是
serde 派生与分行）；本机那条走的也是这套形状；断线重放要的读口（最新一屏、往旧、往新）
已经在 api 上。

---

## 3. 网页前端

**长成什么样**：浏览器打开就能用；手机和电脑两种比例都好看；流式输出顺畅；不引前端框架、不引
构建工具、不用 npm —— 前端那点 JS 只用浏览器自带的几样（`EventSource` / `fetch` / `createElement`）。

**留了什么口**：「一段正在写」与「一块已落定」在流里分得开（`Live` 对 `Blocks`），前端不用猜什么
时候重绘。Markdown 与代码高亮的渲染今天住在**终端前端**里（`pulldown-cmark` / `syntect`，只有
`src/tui/**` 用），浏览器那一侧要自己解决，或者以后把渲染搬到服务端 —— 这一条**没留**。

---

## 4. 外面任意设备操作这台机器

**长成什么样**：手机连上私网（ZeroTier / Tailscale 那种），浏览器打开一个地址，就能在这台电脑上
干活；命令跑在这台机器上，密钥也留在这台机器上。

**留了什么口**：工具、循环、库全在 server 这一侧；前端只是个屏幕。认证与加密**没留** —— 只要跨出
本机就必须新加，这一条现在还是空的。

---

## 5. 分叉模式

**长成什么样**：回退可以造分支，而不是把后面切掉；两条分支共用同一段历史，各走各的。

**留了什么口**：库的列表上留着 `kind` 一列；巨物的引用按块号走，天然跨分支成立。今天回退的非剪枝
那条路是一处 `todo!()`。

---

## 6. 上下文缓存

**长成什么样**：一条会话摊平后的消息列表缓存住，不必每轮都从库里重新取块拼一遍。

**留了什么口**：**没留**。今天每轮重建（这是「字节永不漂移」的代价），有意先不优化；等会话那份状态
有了明确主人之后再做。

---

## 7. 跨平台

**长成什么样**：Windows 上也能跑：不用 `setsid`、不用信号杀进程组、目录按 `%APPDATA%` 那一套、
shell 由系统决定（PowerShell 也算一个 shell 后端）。

**留了什么口**：依赖层是干净的（纯 Rust，`rusqlite` 自带源码，`syntect` 用的是纯 Rust 正则，
没有 `libc` / `nix`）；系统识别（族 / 名字 / 架构）已经有，且已经在挑目录时用上。写死的那几处
（时区路径、`setsid`、`kill`、XDG、浏览器路径）还没动。

---

## 8. 子代理

**长成什么样**：一个回合能把活派给若干子回合（各自一个上下文），主回合只看它们的结论。

**留了什么口**：循环里那道「工具轮数栅栏」—— 就是为将来限子代理的工具次数留的，别删。

---

## 9. 多语言

**长成什么样**：

- 所有跟人直接打交道的文字 —— 旁白、占位符、命令说明、错误提示 —— 按语言分。**给模型看的一律
  英文**（省 token；中文只出现在给人看的地方）。
- **默认文案住在专门的文件里**，一份语言一个文件，不写进 Rust 源码 —— 想加一门语言的人只动那个
  文件夹；想改一句话的人也不用去源码里找位置。
- 语言是**全局**的一枚值（一个进程一份），不做「每个前端一种语言」；程序读系统语言，另有一条命令让
  用户自己挑。
- 配置文件里**占位符单独一片区域**，与别的区域隔开：人好找，程序也好按区域定位、按区域恢复。用户
  只写自己改过的那几条，其余的仍取默认那一份（默认那一份永远住在程序里，所以以后改进文案，
  没动过的人自动跟着好）。
- 一台全新机器第一次跑的时候把配置文件初始化出来（含语言这一枚），之后用户直接改那个文件，不必
  再去找模板。

**留了什么口**：占位符本来就是「库里存名字、渲染时问配置」，所以换语言只动渲染那一头；内置提示词那
一套（`prompts/` 一个文件一段、`include_str!` 进二进制）就是「默认文案住在专门文件里」的先例，
照它来即可；配置的 bootstrap（没有 `config.yaml` 时写一份出来）已经在跑。

**还没留的 / 还没定的**：

- **热重载**还没有：今天配置那些值是启动时读的快照。方向已定（一条命令触发，重读两个文件、更新自己
  那份值；需要新值的人自己再拿一次）。
- 键的形状：`placeholder.switchBill` 做成「一枚叶子 + 语言」的映射，还是语言放在前面
  （`placeholder.zh.switchBill`）。
- 命令说明（`src/commands.rs` 的 `detail`，现在就是中文）与 `bash` / `cd` 那类错误提示，都要从源码
  搬进那套文案文件。
- Windows 上「系统语言」怎么读：std 没有直接答案（unix 看 `LANG` / `LC_ALL`），没辙就先退回默认。

## 10. 事件钩子（`hooks.json`）

**长成什么样**：把事件出口对用户开放 —— 程序内部那些事件（回合开始、模型正在回复、回合结束、出错）
和系统环境事件（尺寸变化、焦点得失、终端没了）都能挂一条命令，用户自己写：回合开始放一段音效、
模型在回复时改终端标题，诸如此类。

- 与 `config.yaml` 同处一份 `hooks.json`，键是事件名，值是一条命令。
- 事件发生就起一条命令，不挡自己：`bash -c`（Windows 上是 `pwsh`，按系统挑），事件名与会话、回合
  这些上下文随环境变量给进去。
- 服务端与前端必定在同一台机器上（不在一台就直接拒绝服务），所以由谁执行不重要；默认交给服务端。
- 条件类钩子（「回合结束**且**焦点不在」）要多跨一道：焦点是前端的事实，服务端要知道就得前端先
  告诉它。

**留了什么口**：事件正在归一化成一个类型、由主循环统一产生、下发只有一条路（见 `TUI-设想.md`
第三节）—— 出口只有一处，钩子挂上去就行；系统识别（族 / 名字 / 架构）已经有，挑 shell 时能直接用。

**还没留的 / 还没定的**：

- 出口本身没有：今天没有任何「事件发生 → 起一条命令」的地方。
- `hooks.json` 放哪（与 `config.yaml` 同处，还是仓库里）、键怎么写（事件名精确匹配，还是允许通配）。
- 上下文给命令什么（事件名、会话名、回合号），走环境变量还是参数。
- 条件类怎么表达（「且焦点不在」这种）。
- 命令的输出怎么办：丢掉，还是收进来当一条旁白。
